## 2. Exhaustive File-by-File Technical Directory

### 2.1 Backend Core & Configuration

#### `backend/server.js`
- **Type:** Backend Core Entry File
- **Purpose:** Central HTTP server configuration and lifecycle manager.
- **Functionality:** 
  - Initializes Express application on port `5000` (or `process.env.PORT`).
  - Configures CORS for `http://localhost:5173` and `http://127.0.0.1:5173`.
  - Configures body parsing (`express.json({ limit: "50mb" })`, `express.urlencoded`).
  - Mounts static file server on `/uploads` pointing to `backend/uploads/`.
  - Initializes database persistence via `initPersistentStore()`.
  - Initiates MongoDB connection via `connectDB()`, running `seedDatabase()` and `syncAllToMongoDB()`.
  - Mounts automated audit logger middleware `auditActivityLogger`.
  - Mounts all 12 modular Express routers under `/api/*`.
  - Sets up Server-Sent Events (SSE) at `/api/realtime/stream`.
  - Implements port conflict fallback handler (`EADDRINUSE`).
- **Imports:** `express`, `cors`, `morgan`, `dotenv`, `path`, `fs`, `url`, all routes in `./routes/*`, `./config/db.js`, `./config/seed.js`, `./config/storageEngine.js`, `./middleware/auditMiddleware.js`, `./utils/realtime.js`.
- **Dependents:** Executed directly via `npm run dev` or `node server.js`; bridged by `api/index.js` on Vercel.

#### `backend/config/db.js`
- **Type:** Backend Configuration
- **Purpose:** Mongoose MongoDB connection establishment and event monitoring.
- **Functionality:**
  - Manages Mongoose connection to `process.env.MONGODB_URI` (default: `mongodb://127.0.0.1:27017/qms_database`).
  - Implements connection timeouts (`serverSelectionTimeoutMS: 3000`, `connectTimeoutMS: 5000`).
  - Exposes `connectDB()` which gracefully handles offline databases without crashing.
  - Exposes `getDBStatus()` returning connection status, URI, and state.
- **Imports:** `mongoose`, `dotenv`.
- **Dependents:** Imported by `backend/server.js`.

#### `backend/config/seed.js`
- **Type:** Backend Database Seeder
- **Purpose:** Initial collection synchronization and data integrity verification.
- **Functionality:**
  - Seeds users with bcrypt hashed passwords (`bcrypt.hash("1234", 10)`).
  - Populates collections (`Document`, `Task`, `Process`, `MRM`, `Audit`, `ExternalAudit`, `Notification`, `Employee`, `Activity`) from reference datasets when collections are empty.
  - Syncs existing records back into memory when MongoDB has data.
- **Imports:** `mongoose`, `bcryptjs`, all models in `../models/index.js`, all reference datasets in `../data/*`.
- **Dependents:** Imported by `backend/server.js`.

#### `backend/config/storageEngine.js`
- **Type:** Backend Persistence & Audit Synchronization Engine
- **Purpose:** Provides file-backed JSON database persistence (`backend/database/*.json`) with dual-mode MongoDB mirroring.
- **Functionality:**
  - Guarantees 100% data persistence even when the local MongoDB daemon is offline.
  - Exposes `saveItem()`, `updateItem()`, `deleteItem()`, `recordActivity()`, `syncAllToMongoDB()`.
  - Maintains `users.json`, `documents.json`, `tasks.json`, `processes.json`, `mrm.json`, `audits.json`, `externalAudits.json`, `activities.json`, `notifications.json`.
  - Emits real-time SSE events via `broadcastRealtimeEvent()`.
- **Imports:** `fs`, `path`, `url`, `mongoose`, `../utils/realtime.js`, all data files in `../data/*`.
- **Dependents:** Imported by `backend/server.js`, `backend/controllers/userController.js`, `taskController.js`, `documentController.js`, `processController.js`, `activityController.js`, `backend/middleware/auditMiddleware.js`.

### 2.2 Backend Middleware & Utilities

#### `backend/middleware/authMiddleware.js`
- **Type:** Backend Security Middleware
- **Purpose:** Token verification and role-based access control.
- **Functionality:**
  - `authenticateToken`: Extracts `Authorization: Bearer <token>`, verifies JWT against `JWT_SECRET`. Resolves user from MongoDB `User` model if online, or attaches decoded payload.
  - `requireRole(...allowedRoles)`: Protects endpoints by comparing `req.user.role` against authorized roles; returns HTTP 403 if unauthorized.
- **Imports:** `jsonwebtoken`, `mongoose`, `../models/User.js`.
- **Dependents:** Imported by all routes in `backend/routes/*`.

#### `backend/middleware/auditMiddleware.js`
- **Type:** Backend Audit Trail Middleware
- **Purpose:** Automatic event logging for all data mutation operations.
- **Functionality:** Intercepts `POST`, `PUT`, `PATCH`, `DELETE` requests, waits for HTTP 2xx completion, and calls `recordActivity()` with actor, role, endpoint, and payload details.
- **Imports:** `../config/storageEngine.js`.
- **Dependents:** Mounted globally in `backend/server.js`.

#### `backend/utils/upload.js`
- **Type:** Backend File Storage Utility
- **Purpose:** Multer file storage engine and file filter.
- **Functionality:** Configures disk storage in `backend/uploads/`, sanitizes filenames with timestamps, enforces a 25MB file limit, and validates MIME types for PDF, DOCX, XLSX, and images.
- **Imports:** `multer`, `path`, `fs`, `url`.
- **Dependents:** Imported by `backend/routes/documentRoutes.js`, `mrmRoutes.js`, `externalAuditRoutes.js`.

#### `backend/utils/emailService.js`
- **Type:** Backend Communication Utility
- **Purpose:** Nodemailer SMTP email dispatcher.
- **Functionality:** Sends C-DAC branded HTML emails for 6-digit OTP password resets. Falls back safely to terminal console logging when SMTP credentials are not configured in `.env`.
- **Imports:** `nodemailer`, `dotenv`.
- **Dependents:** Imported by `backend/controllers/authController.js`.

#### `backend/utils/realtime.js`
- **Type:** Backend Streaming Utility
- **Purpose:** Server-Sent Events (SSE) real-time event broadcasting.
- **Functionality:** Maintains active client connections array (`clients`), handles `/api/realtime/stream`, and broadcasts events (`USER_CREATED`, `DOCUMENT_UPDATED`, etc.) via `broadcastRealtimeEvent()`.
- **Imports:** None.
- **Dependents:** Imported by `backend/server.js`, `backend/config/storageEngine.js`, and controllers.

### 2.4 Frontend Entry, Context & Core Components

#### `QMS-main/src/main.jsx`
- **Type:** Frontend Root Bootstrap
- **Purpose:** Mounts React application into the DOM (`#root`).
- **Imports:** `React`, `ReactDOM`, `App`, `./index.css`.
- **Dependents:** Invoked by browser via `index.html`.

#### `QMS-main/src/App.jsx`
- **Type:** Frontend App Wrapper
- **Purpose:** Encloses the application within global providers:
  - `<BrowserRouter>`: Client-side routing.
  - `<AppProvider>`: Global state management.
  - `<AppRoutes>`: Route resolution.
- **Imports:** `React`, `BrowserRouter`, `AppProvider`, `AppRoutes`.
- **Dependents:** `QMS-main/src/main.jsx`.

#### `QMS-main/src/context/AppContext.jsx`
- **Type:** Frontend Global State Manager
- **Purpose:** Central application state hub managing authentication session, JWT tokens, and real-time synchronized data entities.
- **State Maintained:** `currentUser`, `token`, `documents`, `tasks`, `processes`, `notifications`, `usersList`, `mrmList`, `auditList`, `externalAuditList`, `activities`, `dashboardStats`, `employees`.
- **Key Methods:** `loginUser()`, `logout()`, `refreshData()`, `silentRefresh()`, `uploadDocumentWithFile()`.
- **Imports:** `React`, `authService`, `documentService`, `taskService`, `notificationService`, `processService`, `userService`, `dashboardService`, `mrmService`, `auditService`, `externalAuditService`.
- **Dependents:** Used throughout the entire component tree via `useApp()`.

#### `QMS-main/src/routes/AppRoutes.jsx`
- **Type:** Frontend Route Switcher
- **Purpose:** Defines all URL route patterns, binds them to page components, and enforces role-based dashboard redirects.
- **Dependents:** `QMS-main/src/App.jsx`.

#### `QMS-main/src/components/layout/DashboardLayout.jsx`
- **Type:** Frontend Layout Shell
- **Purpose:** Wraps all authenticated pages with `<Sidebar />`, `<Header />`, and `<Outlet />`.
- **Dependents:** `QMS-main/src/routes/AppRoutes.jsx`.
