- **Mongoose Model:** `User` ([backend/models/User.js](file:///c:/Users/WBL/Downloads/QMS-main-updated/backend/models/User.js))
- **Collection Name:** `users`
- **Query/Operation Executed:**
  - Find all: `User.find({}).sort({ createdAt: -1 })`
  - Create: `bcrypt.hash(password, 10)` followed by `User.create(userData)`
  - Update: `User.findOneAndUpdate({ id: req.params.id }, { $set: updateData }, { new: true })`
  - Status Toggle: `User.findOne({ id })`, flip `user.status = user.status === 'Active' ? 'Suspended' : 'Active'`, `user.save()`
  - Delete: `User.findOneAndDelete({ id: req.params.id })`
- **Fields Affected:** `id`, `username`, `email`, `employeeId`, `password`, `name`, `role`, `roleTitle`, `department`, `process`, `status`, `privileges`.

### F. Complete Execution Flow
1. **User Action:** Administrator clicks `"+ Add New User"` button in `UserManagement.jsx`, fills in user details, and submits the form.
2. **React State Update:** `setIsSubmitting(true)` is set; modal displays loading spinner.
3. **API Dispatch:** `userService.createUser(formData)` sends `POST http://localhost:5000/api/users` with authorization headers.
4. **Route Match:** Express mounts `userRoutes.js` under `/api/users`, matching `POST /`.
5. **Middleware Execution:**
   - `auditActivityLogger` intercepts request.
   - `authenticateToken` validates bearer token and populates `req.user`.
6. **Controller Logic:** `createUser` in `userController.js` validates unique email, employee ID, and username; hashes password with `bcrypt.hash()`.
7. **Database Operation:** Mongoose executes `User.create()`, writing to MongoDB `users` collection and syncing to `storageEngine.js`.
8. **Audit Log:** An activity document is created in MongoDB `activities` (`"Created User: John Doe"`).
9. **Backend Response:** HTTP 201 Created with `{ success: true, data: newUser, message: "User created" }`.
10. **Frontend State & UI:** `UserManagement.jsx` receives response, displays `toast.success("User created successfully")`, appends new user to local `users` state array, closes modal, and updates "Total Users" stat badge.

- **Collections:** `users`, `otps`
- **Queries / Operations:**
  - Login: `User.findOne({ $or: [{ username: id }, { email: id }, { employeeId: id }] })`, followed by `bcrypt.compare(password, user.password)`.
  - Forgot Password: `crypto.randomInt(100000, 999999)`, `Otp.create({ email, otpHash, expiresAt: Date.now() + 10*60*1000 })`, and `sendOtpEmail(email, otp)`.

3. **API Call Dispatch:** `authService.login(...)` executes `POST /api/auth/login`.
4. **Express Routing:** Express maps to `authController.login`.
5. **Controller Execution:** Checks credentials against MongoDB `users` collection via `bcrypt.compare()`.
6. **Token Generation:** Signs JWT token incorporating `{ id, username, email, role, roleTitle }`.
7. **Backend Response:** Returns HTTP 200 with JWT token and sanitized user profile object.
8. **Client Storage:** `AppContext.jsx` stores token in `localStorage.getItem("token")` and `localStorage.setItem("user")`.
9. **Global State Update:** `setCurrentUser(user)` is dispatched; `isAuthenticated` becomes `true`.
10. **UI Transition:** `navigate("/dashboard")` triggers; application renders role-specific dashboard for Course Coordinator.
