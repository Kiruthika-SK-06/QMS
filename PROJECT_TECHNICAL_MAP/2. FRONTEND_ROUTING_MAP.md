## 2. Dynamic Dashboard Routing Architecture

When an authenticated user accesses the generic root `/` or navigates to `/dashboard`, the router dynamically selects their destination dashboard based on their verified institutional role stored in `AppContext` and `localStorage`:

```
User visits /
    │
    ▼
Is user authenticated?
    ├── NO  ──► Redirect to /login
    │
    └── YES ──► Check user.role
                  ├── role === "owner"   ──► Redirect to /process-owner/dashboard
                  ├── role === "qm"      ──► Redirect to /qm-group/dashboard
                  ├── role === "Head"    ──► Redirect to /Head/dashboard
                  └── role === "auditor" ──► Redirect to /Head/dashboard
```

When `/course-coordinator/dashboard`, `/process-owner/dashboard`, `/qms-coordinator/dashboard`, `/qm-group/dashboard`, `/trust-head/dashboard`, or `/Head/dashboard` is opened:
- The route component is [`<Dashboard />`](file:///c:/Users/WBL/Downloads/QMS-main-updated/QMS-main/src/components/dashboard/Dashboard.jsx).
- Lines `18-21` of `Dashboard.jsx` evaluate `effectiveUser.role`:
  - `role === "owner"` → Renders `<ProcessOwnerDashboard />`
  - `role === "Head" || role === "auditor"` → Renders `<Head />` (which encapsulates `<HeadDashboard />`)
  - `role === "qm"` → Renders `<QMGroupDashboard />`

## 4. Protected Route & Role Restriction Enforcement

Role-based access is enforced at two distinct levels:

1. **Frontend Presentation & Redirection:**
   - Sidebar links are filtered by `currentUser.role` through `navByRole[currentUser.role]`.
   - On `/version-history`, line `22-24` of `VersionHistoryPage.jsx` strictly redirects Trust Head users:
     ```jsx
     if (currentUser?.role === "Head") {
       return <Navigate to="/Head/dashboard" replace />;
     }
     ```
   - On `/user-management`, user creation controls are exclusive to `qm` and administrators.
2. **Backend API Enforcement:**
   - Endpoints are shielded by `requireRole(...)` in `authMiddleware.js`. Attempting to access unauthorized backend endpoints yields an HTTP 403 Forbidden response.
